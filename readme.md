1) For the simulation one needs to navigate to the CityFlow root directory and run "pip install ."
2) Then go to the frontend folder and open the simulator named as index.html
3) The files replay_roadnet_2_3.json, and replay_2_3.txt need to be input in the frontend
4) simulation_demo video contains the demo video of simulator
5) The simulator takes in files corresponding to RL algorithms to cleverly switch the traffic lights, we didn't do it
6) The video shows vanilla version of the simulation, with default logic, without RL
4) Whole code is from the CityFlow repository, we just tested it by making the main.py as specified in the documentations and modified some parameters
Repo link:
https://github.com/cityflow-project/CityFlow

Installation Guide(only wsl/linux/macOS):
https://cityflow.readthedocs.io/en/latest/install.html

5) Steps for running can also be found in the docs folder in CityFlow
